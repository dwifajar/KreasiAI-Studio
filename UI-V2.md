# KreasiAI Studio — UI V2 Aurora Neon

UI refresh focused on a premium, modern creative SaaS look.

## Visual direction
- Obsidian / deep-navy workspace
- Aurora gradients: electric violet, cyan, subtle pink
- Glass panels with soft borders and depth
- More pronounced hierarchy for hero, metrics, workflow cards, editor panels, and navigation
- Responsive layout retained

## Functional scope
This package is a visual refresh on top of the working Phase 9 codebase. Existing application features are preserved; only styling/theme improvements were added.

## Run
Copy `.env.local` from the previous working project, then:

```cmd
npm install
npm run check:ffmpeg
npm run dev
```
